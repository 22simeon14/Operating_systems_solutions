# Operating Systems Solutions

This repository contains my solutions, notes, and practice materials from the university course **Operating Systems**.

## Overview

The purpose of this repository is to document and organize my work throughout the course in a clear and structured manner. It serves both as a study resource and as part of my technical portfolio.

The content focuses on practical problem-solving and command-line usage, reflecting my understanding of core Operating Systems concepts.

## Topics Covered

* Linux/Unix command-line fundamentals
* File and directory manipulation
* Shell commands and options
* Process-related operations
* Course exercises and their solutions
